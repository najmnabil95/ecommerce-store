# متجر النخبة الفاخر للأزياء والتجارة الإلكترونية (Elite Luxury Store) 🛍️✨

منصة متكاملة وفائقة التطور للتجارة الإلكترونية للأزياء والملابس الفاخرة، مبنية بأحدث معايير الويب العالمية، وتتضمن واجهة مستخدم تسويقية فاخرة ولوحة تحكم مشرف تنفيذية بمستوى أنظمة SaaS العالمية (Shopify Polaris / Linear / Stripe).

---

## 🌟 أبرز مميزات المتجر والواجهة الأمامية (Storefront)
- **تصميم عصري فائق الجمال والرشاقة:** دعم كامل للغة العربية (RTL) وخطوط أنيقة مع دعم الوضع الليلي والفاتح (Dark / Light Mode).
- **حاسبة المقاس الذكية (Smart Size Calculator):** خوارزمية لتحديد المقاس المثالي حسب الطول والوزن وتفضيل قصة الملابس.
- **دليل مقاسات تفاعلي (Interactive Size Guide):** جداول قياسات دقيقة للبدلات، الثياب العربية، الكاجوال، والأحذية.
- **سلة تسوق ذكية ودرج سحب جانبي:** شريط تقدم الشحن المجاني التلقائي، تطبيق كوبونات الخصم، وتحديد خيارات الدفع.
- **إتمام الطلب السريع والدفع الآمن:** دفع عند الاستلام، بطاقات مدى وفيزا، Apple Pay، مع توليد فوري لرقم الطلب.
- **نظام تقييمات ومراجعات حية:** لكل منتج مع توزيع النجوم والتعليقات.
- **مساعد الدعم الفني الذكي المباشر (AI Live Chatbot):** ردود فورية وإرشادات تفاعلية للشحن والضمان.

---

## 👑 لوحة تحكم المشرف التنفيذية (Executive Admin Portal)
- **نافذة الأوامر الفورية Spotlight (`Ctrl + K`):** بحث ذكي شامل في المنتجات، الطلبات، والصفحات وتنفيذ الإجراءات السريعة عبر اختصارات لوحة المفاتيح.
- **لوحة المؤشرات التنفيذية (Executive Dashboard):**
  - فلاتر زمنية مرنة: (اليوم، آخر 7 أيام، هذا الشهر، كل الأوقات) مع إعادة رسم المخطط البياني التفاعلي للمبيعات (SVG Trend Chart).
  - توزيع حالات الطلبات النشطة ونسب الإنجاز.
  - قائمة المنتجات الأكثر طلباً ومبيعاً ومعدل إنفاق العميل (AOV).
  - مؤشر نبض محرك MariaDB اللحظي وسرعة الاستجابة (Latency).
- **العمليات الجماعية للمنتجات (Products Bulk Operations):**
  - شريط عائم سفلي ذكي عند تحديد المنتجات.
  - تعديل المخزون بالجملة (تعيين، إضافة، إنقاص).
  - تعديل الأسعار بالنسبة المئوية (+% أو -%).
  - نقل المنتجات إلى أقسام وتصنيفات أخرى.
  - حذف جماعي للمنتجات المحددة.
  - معاينة مكبرة للصور عند تمرير الفأرة (Hover Zoom).
  - تصدير كشف المنتجات إلى CSV.
- **إدارة الطلبات والشحنات:**
  - تبويبات حالات الطلب مع عدادات رقمية فورية.
  - تعديل جماعي لحالات الطلبات.
  - زر محادثة واتساب مباشر مع العميل برسالة رسمية جاهزة ومكتوبة مسبقاً.
  - وسام العميل المميز (VIP Badge).
- **الفاتورة الضريبية المبسطة المعتمدة (ZATCA Tax Invoice):**
  - متوافقة مع متطلبات هيئة الزكاة والضريبة والجمارك مع رمز الاستجابة السريعة (QR Code).
  - جاهزة للطباعة بحجم A4 بنقرة واحدة.
- **بوليصة تجهيز الشحنة ومطابقة المقاسات للمستودع (Warehouse Packing Slip).**
- **مركز صيانة MariaDB وفحص المخططات (Database Optimization):**
  - تنفيذ `OPTIMIZE TABLE` و `ANALYZE` وتفريغ كاش النظام.
  - كشف تفصيلي بحالة الجداول وحجم الذاكرة المستهلكة ونوع المحرك `InnoDB`.

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **الخلفية (Backend):** Laravel 12 / PHP 8.3 RESTful API.
- **قاعدة البيانات (Database):** MariaDB / MySQL.
- **الواجهة الأمامية (Frontend):** Vanilla JavaScript (ES6+), Modern Semantic HTML5, CSS3 Glassmorphism Design Tokens.
- **الأيقونات والخطوط:** FontAwesome 6 Pro, Google Cairo & Tajawal Fonts.

---

## 🚀 تشغيل المشروع محلياً (Local Setup)

1. **تشغيل قاعدة بيانات MariaDB (XAMPP أو MySQL):**
   تأكد من عمل خادم MariaDB على المنفذ `3306` مع وجود قاعدة بيانات باسم `ecommerce_store`.

2. **تشغيل المتجر عبر ملف التشغيل السريع:**
   ```cmd
   run_store.bat
   ```
   *يقوم الملف تلقائياً بالتحقق من تشغيل MariaDB وبدء خادم Laravel على `http://127.0.0.1:8000` وفتح المتجر في المتصفح.*

3. **بيانات الدخول للوحة التحكم:**
   - **البريد الإلكتروني:** `admin@elite.com`
   - **كلمة المرور:** `admin123`
